## 3. 静态试装结果与需要保留的边界

- **L：** 原画长斜段和低弯连续，没有旧内钩。按新比例，叶尖约(837.5,804.8)，根到低弯的体积自然；但既有侧面tail z2.2在整块dress z4后，几乎所有白尾被拖裙吞掉，完整角色只露紫叶。问题现在是遮挡，继续放大或扭曲PNG会破坏已经合适的比例。
- **R：** 完整U弧、上背刺与独立紫叶可辨认。原画背刺没有倒到腹侧；同样受整块裙遮住大部分白尾，需分根段与外露段。
- **BL：** 保持宽厚根和连续低弯，在裙前、长发后能完整显示外露尾干；叶尖约(751.55,741.8)，横向已在发外。本次不需要把整张向下拖到地面，也不需要额外压窄。
- **BR：** 与BL同类体积和单叶身份，外露段向左，叶尖约(82.725,748.025)。源形可保留，不再有旧投影锐V和下缘背刺。
- **B旧侧弧（已被第0节替换）：** 曲线和单叶完整，叶尖约(141.25,745.5)，从长发左下方露出，裸尾无三角自折叠。需要承认它仍是一张明显侧弯的原画：三维正后时的轴向粗根／上背面没有比BR更明确。可先作为偏左收弯的八向关键姿态，但若要求严格同一空间中性尾形的正后投影，还需原画补出该面；不能用缩窄此图假装完成。

原比例试装也显示L和R弧形姿态不完全镜像：L真尖y≈805，R≈741。它们可以作为不同关键姿态使用，但转向关节需审查是否突然提叶／换曲率；不能把不同原画端点差直接归于“天然透视”而不看动画。新的cage应在有限范围内对齐，不能为了追尖而恢复大幅非刚性挤压。

## 4. 侧面需要分段遮挡

[侧面遮挡对照](../../test-results/review-pass-3/tail-view-rigs/side-occlusion-comparison.png)每行依次为：整尾在裙后、整尾在裙前、根在裙后而mid之后在裙前。对照保持原有身体/头发的真实绘制顺序。

推荐第三种：根段z2.2，mid后外露段z4.2，长发继续在其上。L尤其需要这样才能看见白尾，而不把圆钝根裸露成裙外封口。JSON的`occlusion`包含源内切面：过`mid`、法向朝`low`，前景区域满足`dot(pixel−mid,normal)>=0`。这只是已经可视核对的起始分区；生产实现应让根／末段各画一次，并结合真正裙缘mask，避免两张整尾叠绘或alpha加深。

三个后向暂可沿用整尾主段层级：BL/BR z5、裙z4、发z6；B z2.7、裙z2.5、发z3。根被长发藏住，外露低弯盖后裙。本次静态试装没有把根提高到翅膀位置，也没有让尾巴代替裙／腿装配。

## 5. 应用前后核对

1. 应用前验证JSON的imageSHA256、PNG尺寸及sourceBounds仍一致；重新提取或换原画后重新换算坐标。
2. 静态保持原比例，源root精确落到各向解剖根。L/R用分段遮挡后复核，不能只验裸尾。
3. LBS根据本片骨架和局部中心线分配权重；三个白尾段小幅变形，叶片保持独立轮廓。重点检查接缝背刺、细颈厚度、低弯内侧。
4. 转向只保留一套尾材质。对齐共同cage时核对实际白尾体积和单叶位置，不能以cage节点一致代替表面验收；若源姿态差过大，补中间关键姿态。
5. 新动作必须另行采样。候选2旧run在近落脚、airborne=true但root_y仅约−.94时，仍可让L尾面超地5.17单位；新链的地面检测应使用真实世界轮廓，不能仅按airborne开关。
