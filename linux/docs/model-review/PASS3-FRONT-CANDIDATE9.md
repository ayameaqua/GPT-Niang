## P1-1：旧后脑卷发与五束新卷发叠加，发量与轮廓偏离原角色

源参考为 [原 Coopanion 缩略图](../../test-results/reference-assets/coopanion-gpt-dragon-thumb.png)。原图额发有清楚的主次束，耳前侧发向下延伸，颈侧留空；C9 在下颌周围及耳后堆出密集短卷环。全身回眸图又把这圈短卷放在原长后发上，形成“短卷帽沿接长后发”的层级，不是原发型的自然延续。

`hair.py:23,39` 直接取 `head.frame('back').image` 并整张缩放画出；它仍然是一张带完整外轮廓、垂落束与卷梢的后脑成品图，**不是无卷梢的平滑头壳**。`hair.py:49–53` 随后把五束全部画在这张图前。深度只决定五束彼此顺序，没有让远侧发束被头壳遮住。`width` 最低保持72%，也没有边缘朝向的真正叶片收窄。因此远近发束同时挤在观众眼前。

直接拆层证据：[0°](../../test-results/review-pass-3/front-fix-9/layers-0.png)、[90°](../../test-results/review-pass-3/front-fix-9/layers-90.png)、[180°](../../test-results/review-pass-3/front-fix-9/layers-180.png)。第一列已经有完整卷梢，第二列新增更多卷梢；这不是低 alpha 查看器光晕，也不是 C8 的两套整头 albedo 透明混合。

最低可实施修正：运行版关闭该实验路径并恢复已配准的原生头图。未来若继续共享头发，先制作真正只含头皮/上段发流的基面，移除它自带的卷梢；每束按局部深度分为壳后与壳前，壳后只允许露出壳轮廓之外的部分。以原 FL 的侧发主束、颈侧留白为量尺重新决定可见束数，不能以“5束都有资源”推导“5束必须全部可见”。源 sheet 的完整 crop/rootUV 可继续留用，本次失败主要在组装与遮挡。

## P1-2：白色束根浮在头壳外，软化 alpha 没有形成连接

`hair.py:43` 使用固定横向半径215、深度半径160，根高随后按各原生图 bbox 缩放。实际根在某些方向落到头壳透明处。降低根部 alpha 只把断口变为淡白短刺，未使它埋入头皮。

## P1-3：头壳不随转向投影，刘海与旧皮肤窗口不共用几何

`hair.py:39` 的底壳只随各头图 bbox 改变位置/宽高，没有随 angle 改变纹理投影；所有方向仍保持背头的中央发缝与发流。`hair.py:58–61` 则让前刘海绕另一个曲面移动。皮肤及五官仍由12张 clean-core 的语义窗口/布局插值，而 `head.py:367–370` 把新刘海画好之后再覆盖旧皮肤。因此脸、刘海、壳不是同一个可遮挡的头面。

实际后果：45→67.5°额头大幅打开；56.25°、回眸 .3696秒（60.79°）出现直角断块；90°是大块光额头附在仍正对观众的后脑上；侧后角会出现发丝与肤色边缘在脸前交叉。左右方向的不对称不能全归因于角色发饰，因为面发覆盖的几何本身就不一致。

最清楚的近照是 [56.9847°](../../test-results/review-pass-3/front-fix-9/cull-56.98471.png)：额头有横平竖直的纹理截断。这张图用于观察截断本身，两侧±.001°的微差不是该 P1 的必要条件。[layers-90](../../test-results/review-pass-3/front-fix-9/layers-90.png) 则能分别看到固定后壳、截取刘海与独立肤色形状。

还有一个确定的裁切错误：`hair.py:57,67,70` 把232..434分20行，行高10.1；透明度按每行左上 y0 求值。首行 y0=232 时 opacity=0，第二行 y0=242.1 已为1；最后一行 y0=423.9 仍小于 bottom−10=424，因此末行也为1。声明的10单位渐隐实际变成顶部整行消失、底部完全不渐隐，造成硬横切面。

最低修正：本轮恢复原生 face/hair 配对材质；不要单独把旧刘海裁出后与另一组 skin window 拼接。若重启共享方案，应先让皮肤与头壳采用统一投影和深度，刘海使用相同头面上的对应根/叶片；前方刘海按真实遮挡盖在皮肤之上。根部过渡应烘在源 alpha 或按顶点/像素计算连续权重，不能用10.1单位网格行的单个 opacity 模拟10单位的渐隐。仅把 skin/fringe 两次 drawImage 对调不足以恢复几何对应。

## 已改善项目与后续验收边界

两张完整方向头发材质的中点溶解重影已不再出现；本轮的重复来自成品后壳与新增发束叠放，需分别记录。C6/C7 的旧脸皮白斑、固定ROI切皮肤未重新出现。旧扫描行驱动头发UV的大块横向拉伸在共享头发路径中已移除；不能因此忽略本轮新增的矩形刘海截断与细列闪烁。

耳背实际放大图为 [ear-materials](../../test-results/review-pass-3/front-fix-9/ear-materials.png)，原耳和运行生成耳背的不透明黑像素均为0；根尖模板alpha没有引入新的黑洞。五方向表情、说话和点头组合没有出现新五官双份。7组取消前后0秒裁图完全一致，证据为 [cancel-zero-delta](../../test-results/review-pass-3/front-fix-9/cancel-zero-delta.json)，并已实际检查0–.3秒恢复过程；该检查不替回眸途中坏头形背书。

主上下文后续改为原生8向方向帧后，需要重新验收原生头发与皮肤是否确实回到配对材质、角耳/发饰是否沿同一颈根绑定，以及所有头部动作和取消的实际连接。**8向离散方向动画只能按离散帧动画评价，不能称作已经通过连续3D转头。** C9 的共享连续表面应保留为失败实验记录，不把“没有整图alpha混合”和“C0数值连续”代替角色外观与动作自然性的验收。
