## 结论与判定口径

**用户指出的两个核心问题成立。** 正面 `nod` 的主变化确实是整头上下移动和纵向缩放，没有俯仰透视；`jump` 的腾空主要由整身 `root_y` 平移产生，腿从蓄力到落地均无膝、踝关节变化。跳跃同时有手臂摆动和上身轻微下压，所以精确说法不是“只有一个参数在动”，而是“缺少形成跳跃的腿部受力链”。

在本轮“动作主体、自然结束、明显姿态下取消”三项口径下：**4 项条件通过，26 项失败**。条件通过的是 `wave`、`raise-left`、`raise-right`、`raise-both`：正面实体已有真正的肩—肘—腕分段链，动作成立且取消可平滑收回，应保留。条件是已进入其正面执行视图；从其他方向进入时仍会遇到共用 `turn` 的双人重影，不能称为整个入口工作流通过。其余项目中，`bow`、两项 `tilt`、`point`、`pet` 等主体并非未实现，失败原因须按矩阵区分，不能一概重做或只修改名称。

“通过”仅针对这里实际查看的时间点、视角和默认表情，**不代表全部 8 × 30 × 19 组合通过，也不代表资产画风、所有遮挡、真实鼠标拖拽和气泡布局已验收**。本轮没有用单测数量或 ID 可调用替代视觉结论。

## 必须先修的共用根因

### P0：下肢没有髋—膝—踝—足链，动作名无法由关节运动支撑

冻结 `render.py:21–22` 的父子表没有骨盆或膝踝；真实 rig 的 `legNear/legFar` 各为一整条腿/鞋源片，详见 `E/rig-joints.json`。`motion.py:291–292` 初始化的也是整腿节点。`jump/hop/toss/flap` 在 `294–304` 共用 `root_y` 正弦升降，脚和腿不参与蓄力、离地、回收、触地。`land` 在 `397–400` 仅压低 `upper` 并增加发衣摆动。

需要新增骨盆、左右髋/膝/踝/足跟/足尖标记，以及按方向投影的骨长、前后遮挡关系。先用原片拆分/补齐被遮区域构造能弯曲的链，再建立接触状态。**只增加 `knee` 数值而仍绘制同一完整直腿、只压缩整腿 sy、或将脚点调平，都不算修复。** 证据：[跳跃下肢](../../test-results/review-pass-3/motion/lower-jump.png)、[跑步下肢](../../test-results/review-pass-3/motion/lower-run.png)、[落地下肢](../../test-results/review-pass-3/motion/lower-land.png)。

### P0：取消只保存局部手势，整个身体会瞬间跳回默认状态

`motion.py:183–200` 清空动作、坐姿、携带、睡眠和表情，仅保存 `hands`、`look_back` 与视图混合。`play` 在 `135–154` 同样没有保存全身姿态用于动作替换，故替换也有同源风险；本轮实际逐图检查的是取消，不声称穷举所有替换对。

`E/cancel-peaks.json` 中，同一时刻取消前后直接相减，已经排除自然呼吸的时间差：

应保存完整可见姿态和需要的速度，按接触状态选择退出动作；不能只对 `root_y` 向零补一个线性插值，令脚穿地或在空中站直。具体取消策略见后文。

### P0：正面点头没有俯仰；摇头没有偏航

`motion.py:344–348` 正面 `head.a=0`，只有 ±7 的 y 和 ±1.8% 的 sy；侧面虽有 ±4° 旋转，也没有脸部/下巴相对投影变化。`349–351` 的 `shake` 是 ±10 水平平移加 ±3° 侧倾。真实图中五官、下巴、耳朵、头顶的相对形态基本不变，分别像浮动和晃头，不能等价为点头/摇头。

需要独立 `headPitch` / `headYaw`，并使头冠、脸面、眼鼻口、下巴和头发随轴改变投影与遮挡。正面可用稀疏网格加投影标记或同骨架俯仰关键图；**不能仅将正面 `nod` 自动路由到侧面来规避要求，也不能把 y 幅度加大结案。** 证据：[正面/侧面点头近景](../../test-results/review-pass-3/motion/dense-nod.png)、[摇头近景](../../test-results/review-pass-3/motion/dense-shake.png)。

### P1：坐起是两套下半身溶解，转向是两个完整人物溶解

`render.py:490–494` 对坐图加 alpha、对站立腿/裙/尾/翼减 alpha。中段实际出现两组脚和尾巴；平滑 alpha 只改变重影的时间曲线，不能形成屈髋屈膝。`render.py:444–449` 的方向混合经过正确的预乘 PLUS 权重合成，但在两个轮廓不同的角色之间仍产生双头、双轮廓、半透明非重叠区域。它修好了混合数学，并未实现身体旋转。`look-back` 已保持后侧身体，仍在两套头部之间溶解。

证据：[坐下](../../test-results/review-pass-3/motion/sit.png)、[站起](../../test-results/review-pass-3/motion/stand.png)、[连续转圈](../../test-results/review-pass-3/motion/continuous-spin.png)、[回眸近景](../../test-results/review-pass-3/motion/head-look-back.png)。

### P1：多个运动使用不适合受力的共用 root 或循环

- `render.py:455–458` root 旋转始终绕局部 `(425,969)` 脚底附近点；`carried` 绕此点摆动，所以像倾斜的悬浮站像，不是由上方抓持点悬挂。
- `walk/run` 只有整腿摆动；正背面用整腿 sy 缩短替代屈腿。`run` 侧面两臂在 `motion.py:328–329` 被覆盖成固定 38°/32° 倾斜，不再交替摆。
- `walk/run` 的 12 s 动作共用时长比例 envelope（`257`），起势达到满幅需要 2.16 s，收尾持续 2.64 s；循环相位来自全局 `clock`，与开始步、步态接触没有显式关系。
- `shiver` 主要是整个人连脚一起 ±4 坐标的水平抖动；`dizzy` 主要是整身绕脚底摇；`poke` 不论被戳方向都向同一水平正向移动。

| `land` 放下 | 从真实 carried 进入；carry 渐退，上身按正弦压 22、头发/衣服有回弹；腿回直后不屈膝吸震；自然结束正常 | 起始段残留 carried 与下压同时瞬清。**失败**：发衣回弹实现了，腿部接地吸震没有实现 |
| `toss` 画布内抛落 | 复用 jump 轨迹，高 180，横移正弦 35、转 14°；没有实际释放速度，腿不回收；最后落回原位 | 顶点立即下跳 179.315 并回正。**失败**：是倾斜的图像升降，不是抛出—抛物线—落地 |
| `pet` 摸头 | 作为被用户摸头的反应：开心表情和头部小幅约 4° 摆动可辨；自然回中。没有自己伸手摸头不算缺陷 | 峰值头角/表情立即复位。**失败就完整反应与取消**：主体可保留，需接触方向、头颈承压与完整收尾 |
| `poke` 戳一戳 | 惊讶表情，整人按一次正弦向 +x 移 12，脚一起滑；与被戳方向无关；自然回位 | 偏移与表情立即清空。**失败**：缺局部冲量、反向回弹和支撑脚稳定 |
| `look-back` 回眸 | API 到后侧；后侧身体保持，头混到侧脸，保持后再回来；不再是整个身体翻面；混合段仍双头/角，颈发遮挡不是转头过程 | `look_back` 本身能 .18 s 回收，另有头 3°小角瞬清。**失败**：局部混合的状态机制有效，头的透视与遮挡过渡未合格 |

## 最低可接受动作设计、素材要求与可落地参数

以下数值是供实现开始调试的范围，采用 **1280 设计坐标和角度**，不是本轮已渲染验收的修复结果。小角色展示尺寸下仍应能读出关节变化；不能只在骨架调试图中看见。

### A. 地面、腾空、悬挂共用的真实下肢

新增每侧 `hip → knee → ankle → heel/toe`；骨盆与胸腔分开。上腿、小腿、鞋分别绘制，在膝和踝后补足重叠区域；裙摆/袖摆掩盖接缝而不掩盖动作。侧面需要明确膝朝向和远近脚顺序，正面需要小腿前后深度、鞋面/鞋底可见性或对应透视关键片，不能把正面侧向劈腿当迈步。

| 动作 | 最低运动设计与初始参数建议 | 必需源片/透视与退出 |
|---|---|---|
| `jump` | 预备 0–18%：膝屈 20–35°、骨盆下降约 25–45；蹬伸时髋膝伸直与踝蹬 15–25°；空中膝收 25–45°；触地再屈 35–50°后恢复。高度可保留 100–145，飞行阶段由单独 vy/g 或 `4h*q*(1-q)` 控制 | 分腿/鞋链与站/屈腿时裙内遮挡；起跳前脚底锁地，落地脚尖→足跟接触。取消走当前速度下的下降/着地，不直插 idle |
| `hop` | 同一物理链的轻量档，骨盆蓄力 10–20、膝 12–20°，高度 35–60、较短滞空，落地轻吸震；应与大跳在幅度和节奏上可区分 | 可复用 jump 素材，不需另画整人；取消依然落地，不能以“小”省略关节 |
| `toss` | 捕获释放速度 vx/vy 和角速度；抛物线推进到足底触地，空中腿放松/回收、发尾滞后；触地转入 land | 同一腿链、身体旋转轴、释放点/速度。没有真实输入时也应有明确示范冲量，不能始终正弦回原点；取消安全落地 |
| `land` | 接触前先伸脚准备，接触后膝髋 20–40°吸震、骨盆短下沉，再 .2–.35 s 回正；发/衣/尾晚于躯干衰减，保留本次已正确回填的 hair warp | 同链和 contact；幅度由下降速度决定。取消应完成接地吸震最低阶段，再退出 |
| `carried` | 使用实际抓持点 `grabAnchor`；身体质心悬在抓点下，腿重力下垂/轻屈 10–25°、踝放松，摆角受拖拽速度影响并阻尼衰减。进入/保持/释放为独立状态 | 原分片可作起点，肩/衣被拎起处要有局部拉力或遮挡；需抓点而非脚底 pivot。释放与取消统一接下降/land，保留速度 |
| `walk` | 每步约 60% 支撑、40% 摆动；支撑脚相对地面固定，摆动脚沿抬高 12–28 的弧线前进，髋膝踝共同解算；局部 gaitPhase 连续推进。起步/停车约 .15–.3 s 独立于 12 s 总时长 | 同链；正面需真实前后投影。角色窗若平移，支撑脚必须按世界/窗口速度补偿，避免脚在地面滑。取消收完当前换重心，≤约 .25 s 后双足站稳 |
| `run` | 步长约 70–110、抬脚约 30–55，可先取范围下沿；明确蹬地、腾空、屈膝回收、落脚；手臂与对侧腿反相摆，不固定 38°/32°；身体前倾约 6–12°与速度一致 | 同链，鞋底/腿回收透视；不能仅把 walk 加速。取消减速完成接地，不把腾空脚瞬间并拢 |
| `dance` | 至少一个明确左右交重心的两拍/四拍短句，支撑膝屈 10–25°、另一脚点地/收回，胸和头有有限反向补偿；手腕与舞步共用拍点 | 保留现有正面手链，新增下肢链即可；不必新画整人。取消由当前拍落到支撑姿态，随后全身恢复 |

### B. `sit` / `stand`：保留原坐图作终点，必须重建路径

**建议不是在“原 sit 图遮挡切换”和“髋膝路径”中二选一，而是髋膝路径为必要条件，原图只提供可用终点。** 原图的坐姿轮廓和衣裙细节可以保留；整张坐图 alpha 不应继续承担运动本身。

1. 坐下先保持双足接地，骨盆向后下方走、躯干略向前补偿，髋屈与膝屈同步增加；不能上身先下降而两条直腿原地不动。
2. 若原坐图终点为向前伸腿的地坐姿，必须有从蹲身到落座、臀部接地、腿再前伸的阶段；不能从站立鞋的位置直接换成远处坐姿鞋。重心由双足转到臀/坐面，脚才可改变约束。
3. 把原坐图至少拆成坐裙/遮挡层、左右大腿/小腿/鞋、尾部。几何链接近同一终点后，只在确实被不透明裙摆遮住的局部交接；两组腿/鞋/尾不能同时半透明。裙摆掩盖一次整图硬切仍会让可见鞋和尾瞬移，不是可靠方案。
4. 如果原包确实缺少深屈膝和被衣裙挡住的纹理，最低补 2–3 个同骨架的蹲身/落座关键片或局部腿片；不能靠拉长皮肤/鞋或缩成细线代替。

| 动作 | 最低过程 | 素材/退出 |
|---|---|---|
| `sit` | 约 .9–1.3 s：重心后移+屈髋屈膝 → 靠近坐面 → 臀部承重 → 腿移到原图终点 → 持续休息 | 原 sit 是终点；需要上述中间腿/裙/尾遮挡。取消未落座可沿受力路径回站，已落座走 stand；不得 `seat=0` |
| `stand` | 从坐姿先把足收至膝下，再躯干前倾将重心移到足上，最后髋膝蹬伸、躯干回正。地坐姿尤其不能直接把站腿淡入 | 同一中间源片可反用，但重心时序不应机械倒放。取消按当前接触选择回坐或完成站稳，避免停在无支撑姿势 |
| `sleep` | 先坐稳，再渐闭眼、头俯垂约 5–10°，呼吸慢于清醒；保持睡眠时不要继续原有活跃手脚动作。醒来先开眼/抬头，随后按请求 stand | 复用坐姿和新增 headPitch；不必强求躺睡，但要明确“坐着睡”。取消先醒/再起身，不瞬站 |

### C. 头颈、观察与回眸

头部必须有同一个颈部连接点、可跟随姿态的眼眉口与前后发层。现有整体旋转可保留给真正的侧倾；pitch/yaw 要有独立参数和投影标记，不能统统映射为 screen roll。缺少被遮区域时，应准备局部额头/下巴/耳后/颈部关键片。

| 动作 | 最低设计/参数建议 | 源片、透视、取消 |
|---|---|---|
| `nod` | 一个清楚的“下点→稍上抬→回中”，向下 pitch 约 10–14°、回弹向上 2–4°，颈根整体平移只作小幅补偿（约 ≤2）。可做两次，但节奏须可读 | 正面眼线、鼻口、下巴/头冠投影必须相对改变；网格/投影与 2–3 张同骨架俯仰关键片皆可。侧面可绕颈转 10–12°并加发滞后；全头返回 .15–.25 s |
| `shake` | yaw 左右约 8–12°，约 2 次 .8–1.2 s，颈根保持；禁止 x±10 作为主要运动 | 远近眼/耳、鼻方向和脸宽随 yaw 变化；使用头部小角关键片或有效投影，非整身转向。取消保持当前头形并回正 |
| `look` | 眼先动，头 yaw 随后到左右目标，各停看约 .25–.4 s，再回中；小范围上/下看可独立加 pitch | 同 yaw 系统；现眼动可保留，roll 不替代观察。取消头与 gaze 一起平滑回收 |
| `tilt-left` | 保留 -12° roll 的现有起势/保持，可加很小肩部补偿和头发惯性 | 不必新增主体素材，检查颈发接缝；补 .15–.25 s 全头/发退出即可 |
| `tilt-right` | 保留 +12° 对应动作 | 同左倾；不可只复位角度而把 hair warp 瞬清 |
| `look-back` | 后侧身体保持，头绕颈逐步回望肩后，保持再返；肩可作约 2–4° 的辅助转动，不能整个身体翻到正面 | 至少有后侧→回眸中间头形、颈/耳后与发层遮挡；现目标侧脸可参考但整头 crossfade 不够。退出保留 look_back 的平滑，并将额外头角也加入 |

### D. 正面手势：保留有效的分段链

`articulation.py` 的 `arm_chain` 使用实际上臂/前臂长度并把子段根接到父段末端；`render.py:547–575` 按段渲染。这批已与早期整袖旋转实现不同。不要为统一“全动作改造”而删除这部分，也不要将正面真实左手误改为画面左手。

| 动作 | 最低保留/改进设计 | 源片和取消 |
|---|---|---|
| `wave` | 保留肩抬/肘屈/腕摆；建议 1.7 s 内 2–3 个清楚腕摆，而非当前约 6 周小幅快速振动；手掌与脸不相穿 | 已有专用掌和分臂可用；保持当前 .18 s 连续手链收回，入口 turn 仍需修 |
| `raise-left` | 保留单侧起势→保持→收回，对侧自然下垂；与角色解剖左右一致 | 现素材可用，无需新整人；保留手链取消 |
| `raise-right` | 同左抬的另一侧，不交换命名 | 同上 |
| `raise-both` | 保留双链同步抬起和稳定持有；若产品定义改为“举过头”才需另加更高目标，不因名称自行判当前无效 | 同上；保持肩肘腕真实连接 |
| `point` | 保留手链与食指掌；在腕部姿态接近后交接掌形，避免开掌/指掌双指影；头与眼朝实际目标。气泡锚点移动时应重新求指尖射线 | 现指掌素材可用；真实气泡 target 坐标变换另需 UI 验证。本轮至少补头、gaze 和手同一退出过程 |

|---|---|---|

### F. `turn` / `spin` 的最低旋转表达

| 动作 | 最低过程 | 素材/透视与退出 |
|---|---|---|
| `turn` | 先换重心/脚尖支点，再胸/头与骨盆有先后转向，最后双足落稳；相邻角度之间应有共同几何标记的位移/形变 | 八视图至少要统一足底、骨盆、颈、头尺度和服饰对应点；中间角用网格插值/小角关键片及前后遮挡切换。alpha 仅用于小面积接缝，不能两个完整人物相加。保留现有取消 settle 意图，但基于真实当前姿态 |
| `spin` | 使用同一转向系统，连贯完成一圈；脚尖轴、身体姿态与发裙滞后保持一致，末段减速收住；.8 s 可保留为快转，但仍需辨认转轴 | 同一多视图几何/遮挡系统；必要时有高速段运动模糊，但模糊不能掩盖主体比例跳变。取消先减角速度到就近落脚方向 |

## 统一取消与动作替换策略

建议新增一个带明确目标和接触状态的全姿态过渡层；不要不断追加 `hand_return/head_return/leg_return` 的孤立例外。记录当前渲染 Pose 的所有运动字段、可用速度及持续状态；表情、视线、头发/衣服驱动也进入同一可见性约束。保留已正确实现的视图 settle 和手链过渡，并让它们与身体一致。

| 当前状态 | 最低可接受退出 | 不可接受做法 |
|---|---|---|
| 双足支撑的头部/手势/鞠躬/轻反应 | 约 .15–.25 s 平滑回中，较大 bow 可 .3 s；必要时用速度连续的 Hermite，脚保持支撑 | 只把 action 清空，或先清头/身体再收手 |
| 走/跑/舞步正在摆腿 | 完成当前支撑转换/短减速，停止点有足底支撑；按实际相位退出 | 直接把两腿角度、scale 变 0/1 |
| 腾空/抛落/扑腾 | 继续有界下降或短安全着地，按落地速度吸震；取消后仍可能需要 .2–.45 s 落地过程 | 从空中插值成站直图同时脚穿地，或直接 root_y=0 |
| 被拎起 | 从当前抓点/速度释放，接下降→land；若仍按住，则取消“动作展示”不应悄悄丢失真实拖拽约束 | 清 carry 后瞬移到地面；绕脚底继续摆 |
| 落座/睡眠 | 未落座时可回站，已坐稳先醒/收足/stand；持续状态直到退出动作完成才撤销 | `seat=0`、`sleeping=False` 同帧完成整个起身 |
| 转向/回眸中间形 | 保持当前实际形体，继续到邻近稳定角度或原位，避免双头重影和突然缩回 | 把插值仅应用到视图 ID，而头颈/身体仍瞬清 |

动作替换必须复用上述出口/入口关系。例如 `jump→wave` 应先安全落地再抬手，`sleep→run` 应先醒来站起再起跑，`bow→tilt` 要保留当前躯干回正。可以队列化，不必强求所有姿态直接混合。本轮未采样所有 900 个替换对，因此这部分是依据当前代码的修复设计与后续验收要求，不能记作已经测试通过。

## 建议实施次序与视觉验收

1. **先修下肢链与接触**：用 `front-left` 和一个可靠正侧面验证 jump/hop/land；同时必须做正面的腿前后投影，不能只用路由隐藏正面缺陷。提供髋膝踝足点随时间曲线，且真实人物图中能看出膝与踝弯曲。
2. **随后修全姿态退出**：取消在蓄力、离地、顶点、接地、坐下中段、坐稳、抬臂保持、头转极值均须逐图查看。取消调用的前后两张应保持相同可见姿态；之后按状态安全恢复。数值连续只作辅助，真实轮廓仍需看。
3. **修正面 headPitch/headYaw**：正面点头必须能看出眼线/鼻/下巴相对位置变化；颈点不能随整头任意飘；头发正确盖住耳颈且不盖错眼口。摇头必须出现远近侧关系，不是水平搬头。
4. **建立坐起中间片和遮挡**：在 `seat=.25/.5/.75` 等节点，画面只能有一套实心腿/鞋/尾；鞋从原位置沿路径移动，不能淡入一套新鞋。看得到屈髋屈膝、坐稳与起身换重心。
5. **基于同一腿链修走跑和舞步**：走有单足支撑、摆动脚离地，跑有屈膝回收和腾空；支撑脚相对地面无明显滑动。三者应有不同的重心/接触时序，不能只改变频率/幅度。
6. **修悬挂、翼拍、转向与回眸**：抓点固定时身体围绕抓点摆；翼有收折与受力；旋转中无两个人/两颗头重叠。方向端点一致性需要与多视图资产审查同时完成。
7. **保留并回归已有效的手链**：正面 wave/左右抬手/双手及 point 的肩肘腕接缝、解剖左右、末段取消；不要让新全姿态层覆盖这些已经连续的参数。

每组至少留起势、受力极值、保持/循环四分相、自然末段、极值取消前后与恢复后的灰底真实渲染；动作参数图、骨架图和自动检查只能补充。脚底漂移、重复图层、比例突变或发/翼/尾穿插应在目标显示尺寸和放大局部各看一遍。验收应报告“实际看了哪些方向和时间点”，不得用“30 ID 均执行”或测试全绿宣称全部运动视觉通过。
