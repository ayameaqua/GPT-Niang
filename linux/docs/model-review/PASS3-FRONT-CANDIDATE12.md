完整动作图也能看见，不仅发生在极端放大下：[右回眸](../../test-results/review-pass-3/front-fix-12/back-right-look-back-targeted.png) 的 .1344/.168秒为247.5°、.2352秒为270°、.3024秒为292.5°，发束中的斑点贯穿多个时点。[右侧动作](../../test-results/review-pass-3/front-fix-12/right-neck-actions.png) 的idle/nod/tilt同样存在。[左回眸](../../test-results/review-pass-3/front-fix-12/back-left-look-back-targeted.png) 的中间方向及 FL 末端也受较轻影响，说明问题不限于原本需要大颈块修补的四张。

根因在冻结 `head.py:138–153`：代码把每个 `eligible && !visited` 像素逐个加入名为 `islands` 的列表，然后对每个像素膨胀半径3。**该列表没有执行颈部连通分量识别，也没有面积/位置/强暖色支持筛选。** 白发原画中的零星暖色采样点同样满足 `r>=b+2 && r>=g+1`；C11中最多是细小单点，C12将它们放大为直径约6模型单位的孔。该循环也无条件跨过真实颈部与头发/下巴的共享边界，故大组件旁的正常轮廓被擦掉。

独立诊断 [warm-components.py](../../test-results/review-pass-3/front-fix-12/warm-components.py) 从未修改的原生crop重新取得420宽输入，复现资格阈值和嘴洪泛，然后只统计未连接嘴的暖色分量；[warm-components.json](../../test-results/review-pass-3/front-fix-12/warm-components.json)保留面积、世界bbox和样例颜色，用于区分大颈块与单点噪声。诊断不改变运行代码。

实际统计：BR有9个组件、其中8个面积≤3；R有33个、其中31个≤3；247有90个、其中82个≤3；292有52个、其中50个≤3。FL全部34个组件最大仅4，left的9个组件均为1。对这些极小组件全部扩半径3，正好解释了为何原本没有大颈块的FL/L也出现小孔。

## 最低可实施修正与验收

1. 从原始未打孔输入重新构建mask，不能在C12已经挖空的 `self.image` 上继续修。将“非嘴暖色像素列表”换成真正的连通分量，先根据已标定颈位置、组件面积、强暖色支持筛选颈岛。小到1–数像素的白发颜色噪点不能独立获得膨胀资格；阈值还需结合组件所在区域，不能只全局删所有大暖色片。
2. 保留完整嘴连通脸域。额外小颈岛只在已经确认的颈部ROI中处理，不能误删270°/247.5°的下巴肤色。各帧的实际颈范围已列在C10报告；bbox作为搜索约束，不作为整块清空矩形。
3. 描边扩张只针对已确认组件的暴露外边，约2–3模型单位。可以要求候选描边同时接近原始透明外域，避免把颈与发/下巴共享的内部边界一起擦掉；必要时为四片记录显式局部清理轮廓，比在整张头图上继续扩大暖色规则可靠。
4. 先做同一四方向的C11/修后近照，逐束检查：颈块/颈边应消失，原发束紫色外轮廓、白色实体与卷尖应保持；任何新圆孔或下巴缺口均失败。再看左右回眸 .1344/.2352/.3024/.504 秒、取消返回、R侧nod/tilt，确保遮罩不是只在静态方向勉强藏住。
