## 4. 正面剩余静态细调

### F-S1：后发中心比脸/身体右偏15（P2，可小改，无需换图）

当前 `hair-back.box=[226.5,180,427,610]`，矩形中心x440；正面 head/身体轴和头枢轴为x425。实际下部后发在画面右侧比左侧略显肥厚，尤其翼下到腰侧的弯发。原源图不完全机械对称，因此不能仅凭框中心要求绝对镜像，但15设计单位的装配偏移没有必要继续保留。

建议先只做一个可逆参数调整：

```text
views.front.parts[id=hair-back].box
[226.5, 180, 427, 610] -> [211.5, 180, 427, 610]
```

这会把几何中心移至x425，并保持原比例/发长。内存试摆的第二格是该方案，左右外轮廓比当前更平衡。第三格把宽度再缩至95%只是诊断对照，**不是建议先执行的必要改动**；先居中后再看是否还需要改发量，不要一次叠加缩放。

验收：正面待机下，双侧后发对翼/袖/腰饰的遮挡合理；结饰所在侧可以略厚，但不能通过整片后发右移去制造差异。当前头片已经包含短后脑/脸框发，长后发只承担继续向下的发量。

### F-S2：短前摆与露腿程度可再贴近基底，但不是当前阻断项（P2，源图局部）

新前摆结构正确，不过底端略低、双腿露出的上段大多为白色袜面；原 front-left 具有更明确的一侧大腿肤色过渡。新裙侧褶的线条也比基底偏硬、层层展开更规整，腰饰相对显眼。这是局部设计/绘制差异，不能通过整体把裙子往上搬解决，否则会改变衣领与脚边长裙的连接。

建议保持当前裙的整体 box `[165,447,520,507]` 与侧裙底 y954；若后续希望进一步贴原造型，仅在源图中把中央前摆最低端提高约 **10–20设计单位**（本版源图约24–48 px），保留两侧长裙和肩领。先并排比较原基底，不必为了这一项立即重画整件裙子。不要把腿放到裙前面来增加露腿。

验收：中央短摆/侧长裙仍是同一件原服装；两腿上段有适度可读空间，前摆不露出不自然的皮肤三角，也不让袜顶直接接到悬空衣缘。

### F-S3：新细线在缩图下更易点断，不应误判为旧裁片故障（观察项）

512接触表和部分768细节中，新头部细发线/裙褶较原基底略有点状采样感；在1280设计尺度的灰底头片中，头顶、刘海和脸框轮廓是连续的。没有发现新一轮矩形截断或实体污染。

建议在常用桌宠实际尺寸再看线条稳定性。若需要处理，应优化细线在目标缩放下的采样/线宽，或源图局部线条密度；不要提高整个贴图的alpha阈值，也不要把它记成已经复发的平顶/串格问题。本轮不要求为此更换新头。

### F-S4：静态肩部仍有大皮肤连接端可见（留给下一阶段，但静态需保留复核）

正面颈领已比原先的长直颈自然，不过两侧肩端与袖口仍像圆形皮肤接头，手掌偏小。这一项来自现有手臂素材和肩连接，是已知后续手臂工作的一部分。本轮不复审手势，不用它否定新脸/头发/腿裙的修复；下一阶段完成后要重新检查静态肩部能否融入原服装轮廓。

## 5. 右前侧：新短摆与镜像原腿

### R-S1：短摆与原腿比例的方向正确（已改善）

新裙替代中央落地长裙后，终于能看见大腿、踝花和鞋；镜像原 `sourcePart` 腿片按原98×323/97×311尺寸显示，局部 `sx/sy=1`，没有旧生成腿0.465/0.512的半宽挤压。原鞋型比旧生成鞋更接近基底，适合继续使用。

但需区分“素材比例已对”与“贴到身体上已对”：当前脚组仍偏在新裙开口左侧，这在旧长裙里被遮住，现在成为明显静态问题。

### R-S2：躯干/前摆相对脚组向右偏，形成左腿柱和右侧大空洞（P1，本轮下一步应修）

当前数据：

```text
dress.box = [170.564, 447, 563.871, 507]
leg-near.box = [340, 646, 98, 323]
leg-far.box  = [411, 652, 97, 311]
legNear pivot = [389, 675]
legFar pivot  = [459.5, 675]
registration.bodyAxis = 425
```

脚组/髋点中点约x424，实际新衣服的前胸/前摆和腰部视觉中心大致在x490–510范围（按前面板轮廓估计，不把它冒充精确解剖轴）。截图中两条腿挤在开口左半侧，远腿上段大量藏入左侧裙，右侧留出大空洞。两只脚本身没有被压扁；问题是新衣服外框中心无法代表 torso/hip 的中心。

[位置试摆](../../test-results/fixes/recheck-front/right-registration-probes.png)给出五格，依次：当前、双腿+40、裙-40、裙-25/双腿+15、裙-55。所有方案仅在内存里改静态位置，没有修肩点，因此用于选择腰腿登记方向，不能直接当成整个人的最终结果。

**优先建议从“裙-25/双腿+15”的有限调整开始人工校准**，它把裙和腿的相对偏差减少40，同时避免把整个脚组直接推到x465。具体初始值：

```text
dress.box.x: 170.564 -> 145.564
leg-near.box.x: 340 -> 355
leg-far.box.x: 411 -> 426
legNear pivot.x: 389 -> 404
legFar pivot.x: 459.5 -> 474.5
```

只改上面数值还不完整。衣裙平移后必须重新检查领口和新裙的两个实际肩端，更新对应肩关节/手臂位置；本轮没有替下一阶段验收肩连接。如果从原角色骨盆/颈根 landmark 判断应保持脚组中点425，则另一条可选路线是保持双腿位置，把衣裙向左移约35–45，并重配肩领。**不要同时采用两条路线，也不要仅因某格腿看起来居中就批量固定参数。**

最终需要用颈根→躯干→骨盆→两脚的实际标记线决定偏移，不能再以宽大侧裙矩形的中心作为身体轴。衣裙源图的侧裙向左拖长，天然会把框中心拉离身体；后续数据最好显式记录 `neck/waist/hip` 的图内坐标。

验收：正面板下两腿能分别从合理的髋位延伸出来；右侧裙开口不再明显空一半；近/远腿透视可以相邻但不能读成一根腿柱。鞋底高度保持969附近，原鞋宽/腿长不变。静态腰腿登记通过后，再进入动作连接。

### R-S3：头与颈胸、五官仍是旧方案，不能因换裙宣称整张右前侧通过

本快照右前侧仍有 `head.warpY=[.73,.83]`、`face.box=[455,315,160,150]` 和旧头内烘焙颈胸/刘海。这里只记录边界，不重复审核这些已知尚未修的部分：本轮对右前侧的正面结论仅为“短摆恢复和镜像原腿比例有效”，不延伸到脸、颈胸或动作已通过。

## 6. 建议按顺序收敛

1. 保留当前正面头/五官/腿鞋基础，先把后发几何中心从440试移到425；用与本报告相同的静态姿态看是否改善，避免同时缩头、缩发、缩裙。
2. 修右前侧衣裙与腿的静态登记，以第5节的有限试摆为起点，重画标记线并校肩领。保留镜像原腿的局部比例。
3. 对正面中央短摆的10–20单位局部调整作原基底并排比较后决定；它可以延后，不应打断更明显的腰腿登记修复。
4. 随后进入已计划的肩臂/手势阶段，再回查静态肩端。该阶段不是本轮已完成工作。
5. 在常用尺寸、768诊断尺寸各保留一组新的灰底 before/after，并记录新的文件哈希。只有静态身份、部件登记和后续动作都分别通过，才能撤掉 experimental/calibrating。
