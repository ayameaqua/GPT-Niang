## 已证实的主要根因

1. **源图裁切与分层有真实污染。** 通用 `GENERIC_CROPS` 把相邻格的发梢、裙片、翼尖裁进当前部件；灰底合成仍显示独立的实心碎片。`trimmed()` 只裁外接矩形，不会移除内部或边缘的其他部件。部分正确主体还被裁掉。这不能全部归因于透明图片查看器噪点。
2. **新贴图与旧枢轴没有一起迁移。** 改了 `box` 后，腿和翼仍会继承原基底枢轴；一些根点已经落在新贴图之外，静态图掩盖了运动时的偏心旋转。
3. **正面脸和头发没有形成一致的正面结构。** 使用原侧脸眉眼比例及口部偏移，再叠头部已有发束、前发和后发，产生不对称五官、重复发束和不自然头颈。
4. **部件被分别拉伸，导致跨方向身材与轮廓漂移。** 方向图不同的裙长与裁图边界、腿宽高比被通用目标框压缩，会表现为脚粘连、鞋尖露出、裙长跳变。
5. **动作调度通过不等于动作表现成立。** 坐姿硬切、表情覆盖手势、前后方向使用相同前倾角度、拎起保持包络衰减，以及“指向”缺少真实指尖/目标锚点，都需要分别修正。

详细证据、数值和文件定位以三份专项报告为准。

## 使用报告时的两个约定

- 专项报告中的 P1 均指“下一轮视觉交付前必须修”的阻断项。本索引的 P0/P1 是实施先后顺序，不能按不同报告的数字直接降级某个问题。
- `FRONT-VIEWS.md` 的源图 bbox 是半开区间 `[x0,y0,x1,y1)`，`SIDE-REAR-VIEWS.md` 的源图 bbox 是闭区间。写入 `QImage.copy(x,y,w,h)` 前先换算，不能把四元组直接当成相同含义。源图像素坐标与 rig 设计坐标也是两套空间；清理裁片改变外接框后，原 box/pivot 需要重新标定。

## 给主上下文的执行顺序

- **P0：固定正确的静态参考。** 先完成原基底、正面和右前侧的同尺度设定；确定脸、发片、服装、脚和饰物，而不是继续给所有 PNG 套同一个目标矩形。没有合格静态设计时，补画源素材，不能靠大幅拉伸、遮罩挖洞或叠同类发片掩盖问题。
- **P0：先清理裁片，再调绑定。** 每个部件核对来源中的完整主体边界；排除相邻部件和误加装饰，同时保留抗锯齿 alpha。新的外接框会改变缩放与锚点，不能在旧错误裁片上先微调坐标。
- **P0：每个视角独立标定绑定。** 同步确定设计坐标、头颈/肩/髋/翼根/尾根枢轴及脚底基线，记录哪些坐标来自该视角，拒绝悄悄继承不适用的原基底值。
- **P1：重做正面的五官与发层。** 使用正面对应的眉眼/口位置、尺寸、遮挡和可见范围；去掉重复的刘海/侧发/后发，检查自然眨眼和全部表情。移动脚的位置时还要检查髋、膝、踝与腿的宽高比。
- **P1：拆开表情和身体动作的控制权。** 表情可以影响面部、局部颤抖等参数，不应覆盖正在执行的抬手；持续动作的保持参数和结束/取消参数应分开。
- **P1：按方向定义动作适用矩阵。** 前倾方向、鞠躬、左右手的解剖语义不能沿用屏幕固定符号。当前视角没有可靠动作时，明确转到已验证视角，或标为未完成，避免相同刚性旋转被多个名字包装。
- **P2：重做可复现视觉验收。** 在中性表情和非中性表情下，检查动作起势、极值、保持、结束/取消；比较相邻方向的身高、脚底、头部中心和饰物位置，再检查真实窗口尺寸/缩放与动态输入区。

修复应按小批次提交：先“正面静态+源片”，再“正面绑定+表情”，再“跨视角关节与动作”。每批保留同样镜头、尺度和时间点的修前/修后图；以具体问题和验收项关闭，不能只增加测试数量或把状态改成完成。
