建议：B缓存权重场可先提高到最长边256；绘制网格可用16×24，或只在内弯／叶颈区增密到相当于32×48的局部精度。注意权重场和绘制网格是两个不同层次，不能只改后者。验收时保留上述源探针，并在原画内缘检查小背刺的墨线，不必重新生成尾图或重跑整套动画。数据见 `inner-edge-resolution.json`，对比图中的高分辨率版本均未应用到运行代码。

本轮旧P1/P2问题可以关闭；两个P3残差应继续记录。结论仅涵盖此次约定的四项尾巴复核范围。
