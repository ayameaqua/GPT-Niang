## 坐站、蓄力起跳与落地

FL sit 从站立、半坐、深坐到稳定坐姿均已看；stand、起身取消、深坐请求 spin 的真实先站后转也已看。坐姿尾根随骨盆调整，裙摆在地面上折叠，发尾留在地面上方。没有 C9 的斜向贴地细条，也没有旧版把紫尾叶压成坐垫横条的现象。

五个侧后方向另采 land `0/.2/.325/.45`、carried `0/.5/.75`，并保留 L/B/R run `3.525` 的旧回归点。尾根未因为骨盆下移、拎起或根旋转而脱开。

## 回眸与尾巴遮挡

BL/BR look-back 采样 `0/.28/.56/.84/1.12/1.4/1.96/2.52/2.8`。身体与尾巴保持原来的后侧方向；头部按其独立方向帧回转。就尾根、尾弧、裙摆与下段长发的关系看，未出现转头带着尾巴换向、原尾突然重绘成另一方向或长发把紫叶完全吞掉的情况。

但头颈专项已确认 BR 的烘焙后颈块，以及回眸时旧后发上缘短卷悬空。这属于 C10 尚未接受的发根／头颈整合问题。C11 计划只清理独立暖色颈块并对 BL/BR 原生后发裁 world 480 以上、淡入至 510；后续须实图确认没有连下段长发一起裁短，且不会重新露出尾根。C10 的尾巴专项结论不覆盖该问题。

## 转身收尾与数值佐证

本实现是**原生八向帧动画**：blend_view 在半程选下一张方向帧，外部 camera_angle 也落到最近原生身体方向。不把这种方向切帧判成新增的连续补间故障，也不将它描述成连续 3D。连续相机补间仍未验收。

在原生衣发恢复后重新取了 56 个 fully tucked 姿态，覆盖全部八个实际尾材质。完整图与禁画尾巴图的 RGB 任一通道差≥12 像素数全部为 0；没有旧版从发缝漏出的细尾边、第二叶或针状物。首尾展开在已查看的 spin 表中没有突然补回一整条尾巴的现象。

283 个实际尾绘制姿态的映射 root 与 `upper(coccyx_point(angle, seat))` 一致，最大误差 0。189 个未主动收拢姿态的骨段长度最大相对变化为 `1.78e-15`。数值与裸尾图一起支持“未恢复旧断根／割腰”结论。

两个明确命令即时边界（起身取消、land→spin）的前后图像差为 0。没有据此扩展承诺所有取消组合均已验收。
