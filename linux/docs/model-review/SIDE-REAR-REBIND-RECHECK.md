## 怎样应用这份坐标表

对不含warp的部件，先选清晰的根UV `(u,v)` 和世界连接点 `(X,Y)`，保持当前宽高 `(w,h)`，再算：

```text
u_draw = 1-u  （仅当 flipX=true，否则为u）
box.x = X - u_draw*w
box.y = Y - v*h
pivot[parent] = [X,Y]
```

不能只移动pivot不移动box，也不能只翻转图像而不翻根UV。left/right头暂保留当前warpY以隔离本批锚点问题；头图原始v需要先经过：`v<=a ? v/a*b : b+(v-a)/(1-a)*(1-b)`，此处a=.73、b=.83。以后去掉warp时必须重新投影，不能复用本表的旧头位移。

下面先把**衣身真正的腰轴**注册到425，再由衣身源图的颈/肩位置生成接点。腰UV来自窄腰而不是包含拖尾/裙摆的矩形中心；upper的y也应对应该真实腰部，不再机械取574。腿盒与腿底本批不动。

## 此批可保留与仍需完成
