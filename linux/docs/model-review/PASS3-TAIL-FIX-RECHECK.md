## 3. P1：横截面在148.326°与328.326°突然整面翻转

位置：冻结 `model/render.py:526–539`，尤其531、537行。

```python
sign = 1 if centre(.6)[0] >= centre(.4)[0] else -1
nx, ny = -dy/length*sign, dx/length*sign
```

这里用屏幕中间两点的左右次序决定**整条尾巴所有横截面的正反方向**。它不是连续的表面朝向：中间两点横坐标相等时，sign从+1直接变成−1，白尾干表面和背刺同时跳到中心线另一边。

在真实idle参数 `time=0, energy=.15` 下，分界为 **yaw=148.325866157°**，另一个是328.325866157°。[关键角度图第二行](../../test-results/review-pass-3/rear-fix-1/critical-yaw-surface.png) 第一、二格仅差.002°：148.324866°仍是右侧背刺和残缺末端，148.326866°直接变成另一侧背刺与完整反钩。没有完整角色遮挡参与这个隔离实验。

实心纹理点 `UV=(.5,.75)`，alpha=253，世界位置：

- 148.324866°：`(476.8141,903.1491)`。
- 148.326866°：`(567.5763,894.8982)`。
- 跳动 **91.1364设计单位**，在768图中约54.68px。

这不是近乎正对镜头时合理的透视缩短，而是离散翻面。根点和中心线本身都可以连续，所以只测 `tail_point` 会漏掉它。分界还随time/energy改变，例如后侧carried1.5s的分界约143.336°；不能只修死148°附近一帧。

**修复路线：** 在身体空间给中心线构造连续的局部坐标架（例如旋转最小的平行传输框架），再将整个截面一起做yaw投影。不要在投影后用全局sign翻纹理。若仍采用薄片，至少要有稳定的正面/背面定义和连续旋转过渡；简单删掉sign仍不足以解决局部切线退化和自遮挡，见下一项。

**验收：** 对每个动作energy/时间，扫过所有角度；实际映射顶点、背刺纹理点和alpha轮廓均连续。覆盖148°/328°附近以及分界随动作移动后的范围，不能只测试八个整数方向。

## 4. P1：只投影中心线，尾面仍是无深度的屏幕带，产生粗钩和自折叠

位置：`model/kinematics.py:90–108`、`render.py:530–539`、`raster_mesh.py`。

`tail_point`有身体空间 `(x,y,z)`，但返回时只保留 `x*cos(yaw)+z*sin(yaw), y`。尾干横截面再沿**投影后2D切线的法向**铺开，宽度由源图y偏移乘 `.27 + .22*sin(pi*t)` 决定。换言之，只有中心线获得空间投影，鳞片面、背刺和横截面没有空间朝向或深度。

真实画面中的后果：

- BL135°中后段在屏幕上趋近折返，横截面却保持大宽度；末端与前段叠压成粗白钩。紫叶尖横过尾干顶部，弯内背刺被压成一条细密锯齿。[BL隔离图](../../test-results/review-pass-3/rear-fix-1/back-left-tail.png)无需去猜身体遮挡即可看清。
- 140°附近末端/紫尖大幅折入尾干，轮廓像被截断；同类问题出现在FR315°、320°附近。[yaw扫描](../../test-results/review-pass-3/rear-fix-1/isolated-yaw-sweep.png)的第三行/最后一行能看到轮廓塌缩。
- BL carried1.5s维持135°但energy改变，尾末端几乎消失成白色斜柱；这是局部投影和曲率退化，**该帧sign仍为+1**，不能全归因于上一项硬翻面。
- B180°能看见裙前主尾干，但内弯仍呈一串挤在一起的背刺，像在裙面挂一条二维J形管。不是因为“J形一定不对”，而是当前表面没有提供该空间深度所需的缩短、背面和段间遮挡。

`raster_mesh.py`按图片row/column依次画三角形，没有3D深度排序。三角形发生翻折或重叠时，绘制顺序不代表实际哪段更靠近镜头。增加48列到更多列只能改善离散精度，不能补出丢掉的深度，也不能禁止带宽超过弯曲半径后发生的折叠。

**两种可实施路线：**

1. 保留统一身体曲线，但让 `tail_point`或新函数返回未投影的3D中心、切线和深度。尾干做有半径的管面/多面截面，保持连续局部坐标架后统一投影；表面按深度处理遮挡。背刺放在固定的身体空间背脊方向，随转角逐渐转到侧面/背面。共享白鳞纹理可继续用于材料，但不能假设一张侧面切图的上下边就是所有视角的正反面。
2. 若CPU贴片方案更合适，补侧面、背部/上表面和必要的内弯差分，并建立可检查的关键投影，沿同一骨架驱动。相近表面间再小幅过渡。补画必须服务于缺失的面，不能把当前坏投影渲染成新PNG再当正确源。

**验收：** 不带裙发的全尾先过关：BL135°、FR315°、140–155°、320–335°，以及carried/high-energy时，尾干体积连续、背脊可追踪、没有线状缩颈或突然多出横向枝杈。随后才用衣发遮挡检查连接。

## 5. P1：紫叶尖受与尾干相同的弯曲/非等比缩放，失去叶片轮廓

新源中的紫尖是横向叶片，白尾干细端进入其中；实际渲染在普通侧向也变成短小三叉，BL又进一步横折。这个问题在完整图默认尺寸下很明显，但容易因“尾巴已能摆动”而忽略。

按冻结映射测 `t=.84–1` 的中心线弧长相对源轴长度：

| 视角 | 叶尖区平均轴向比例 | 同区横向比例 |
|---|---:|---:|
| F/B | .154 | .270–.376 |
| FL/BR | .162 | .270–.376 |
| L/R | .133 | .270–.376 |
| BL/FR | .123 | .270–.376 |

横向保持的尺度约为轴向的1.7–3.1倍，叠加末段局部切线旋转，原本叶尖被压短拉宽。源图主叶约在 `u=.84–1.00`；不应把整个叶片像白尾干一样逐x列沿弧线强弯。

**建议：** 将叶尖作为独立关节/局部面。可先从实际源 `x≈1805–2149`（`u≈.84–1`，全高后用alpha抠出）提取；白尾细端继续深入叶片的区域需补足接缝遮挡，不能按矩形一刀切断。根候选位于 `UV≈(.89,.53)`，即约 `(1914,187)`，在白尾插入叶片的中段附近，需放大确认接缝；tip仍可用现有 `(.997,.435)`。叶片用一致局部尺度约.22–.27作为首轮试配，再根据视角透视投影其平面；不要通过每列改变法向产生三叉。与白尾颈连接留12–20源像素重叠。

上述区域/点是可执行的拆分起点，不是已验收的最终切片。最终先单独看叶片绕关节转动，再检查八向可见形状。需要正背面/侧缘差分时应补画；当前一张侧面叶片无法证明所有角度都已正确。

## 6. P1：land时尾干穿地38.5–40.2单位，walk/run也有轻微穿地

[地面红线图](../../test-results/review-pass-3/rear-fix-1/ground-penetration.png)将同一设计地面y=969画出。每对格是idle与land .325s；此时 `root_y=0, root_angle=0`，不存在整体旋转导致误测的问题。

- land .325s：pelvis.y=48，尾根移动到 `(425,731)`。
- 隔离尾图中alpha>128的最低点：BL/FR约y1007.5，其余方向约y1009.17。
- 对y969的越界：**38.5–40.17**设计单位，768图中约23–24px。完整合成也能看见尾弧伸到鞋底/裙底红线下方。
- neutral尾下缘距离地面仅6.5单位（BL/FR13.2）；walk3.7s穿地约3.5–6.8，run3.3s约2.2–3.8。
- sit最后实际view为front-left，采样尾下缘距地面约18.2单位，没有在该终态复现穿地；这不能代表未实现的后向坐姿已通过。

原因是tail全曲线继承pelvis下移，局部曲线只根据seat变化，没有根据下蹲/地面调整弯曲。新的garment hem约束保持了裙底，却没有作用于尾巴。把tip的bodyY改到135解决不了尾中段的地面问题，当前最低点主要在中弯。

**建议：** 约束**尾干可见半径后的下表面**，不能只限制中心线y。保持根锁在pelvis，对根后弧长区逐渐抬起/侧移，使 `centerY(t)+radiusScreenY(t) <= 969-rootWorldY`；在接触区平滑释放曲率，并保留地面摩擦/延迟的视觉效果。不要裁掉y969以下的像素，那会制造平口断尾。坐下、落地、起跳预蹲、walk/run接触相分别复核。

## 9. 修复优先序与下一轮验收
