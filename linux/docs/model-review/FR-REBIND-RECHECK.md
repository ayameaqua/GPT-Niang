## 本轮结论

1. **保留新头及五官的位置。** `head.box=[190,65,470,470]` 与现有短前摆、原比例双腿能够形成连贯的右转形体。没有必要为了使脸居中而把五官搬到头框中心；新头的脸部透视本来就偏右。旧头烘焙颈胸造成的重复领口问题在本快照中已消除。

应用后的最低验收要求：

1. 在同样的灰底 RGB32 Qt 输出上，0° 头部的拟定颈根 x 与领口中心 x 差不超过 3；两袖帽肤色中心与对应肩中心距离不超过 3，且圆肩不突出成额外球状残肢。
2. 左右头倾 ±12° 的端点和过渡中，颈部保持连接；领缘不能上浮到脸上，也不能露出明显灰底裂口。头、脸、发饰应作为同一头部组运动。
3. `head.box`、全部 face landmarks、裙框和两腿框保持上述值；近脚底 969、远脚底 963，脚组注册 440。实测到新问题再改，不能为消除肩错位而移动双脚。
4. 将角色缩至实际桌宠显示尺寸，确认近远眼大小关系仍清楚、嘴仍在脸上；再放大检查 mask 边缘。不得把图片查看器的低 alpha 预览噪点判作裁片残肢。
5. 后续专门检查上身旋转、左右抬手/双手/指向、走跑、转向及尾摆周期。尤其 `upper` 和两个肩枢轴变更会影响这些动作；**本轮没有验收它们，也不能据此把 `registration.status` 改为 accepted。**

本轮观察到的领肩错位和尾根位置属于装配/绑定问题；这些修正不需要重新绘制新头或五官。人物的短发、脸型与服装是否达到最终原作还原度，仍需结合其余视角和用户视觉反馈统一验收。
